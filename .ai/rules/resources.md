# Resources

## Design rules: grounded, functional UI
Avoid: purple gradients, pill-shaped buttons, emoji icons, em dashes (use hyphens or colons), decorative animation that doesn't serve a functional purpose. Loading states and cart-update transitions are fine; gratuitous scroll/cursor effects are not. Keep the design grounded and functional, not templated. Use Lucide SVG icons only. Use shadcn CSS variables (hsl tokens) and the established component classes (btn-primary, badge-*, card, dialog-overlay/content, input-field, variant-btn, toggle-switch).
